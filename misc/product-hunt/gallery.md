# Gallery

Product Hunt wants at least 2 images. Recommended size 1270x760 PNG, sRGB, under 3MB. First image is the social preview.

## Capture

1. Open each file in Chrome.
2. DevTools → device mode → 1270 x 760, 100% zoom, no scrollbar.
3. Screenshot. Save as 01-hero.png through 05-cta.png.
4. Upload in this order. Do not letterbox. Do not add a browser chrome unless you recapture the live site later.

The HTML slides are branded cards. If you later recapture the live site, keep 01-hero as the branded still (it is the social preview). Good live replacements: https://gainmaps.com/convert, /logos, /photos.
