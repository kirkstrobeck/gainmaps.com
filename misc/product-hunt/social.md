## Reply bank

HDR does not show on my monitor
Ultra highlights only appear on HDR-capable displays (Apple XDR, Android Ultra HDR, Windows Advanced Color). On SDR the JPEG looks normal. That is the format working as designed. You can still download and share the file.

Is this AI?
No. It is a gain-map encode (ISO/TS 21496-1). It rebuilds highlight range from the pixels you already have. It does not generate a new picture.

Does it work on iPhone?
Safari on HDR iPhones can show Ultra HDR JPEGs. Encode on the site in the browser, then save the file. Some share sheets re-encode and drop the gain map — Photos and Files are safer than posting through a social app.

Windows?
Yes, in Chromium on a display with Advanced Color / HDR enabled. If HDR is off in Windows settings, you will see the SDR layer.

Instagram / Twitter / Slack
Many social pipelines strip gain maps and serve a tone-mapped SDR JPEG. The original file still has the map. Download from gainmaps.com and keep that copy.

Is it free?
Yes. The site is free. The CLI is brew install gainmap. Source is on GitHub.

How is this different from raising exposure?
Raising exposure pushes the whole image. A gain map keeps an SDR base that looks right in every app, and only expands highlights where the display can show them.

HEIC vs JPEG
HEIC can already carry HDR. Gainmaps writes an Ultra HDR JPEG so the same file opens as a regular JPEG in apps that do not speak HEIC, and as HDR where the display supports it.
